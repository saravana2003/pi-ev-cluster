# pi-ev-cluster

A Raspberry Pi 5 + 5" touch display turned into a mini EV (scooter) instrument cluster.
An Arduino Uno simulates the vehicle (speed, battery SOC, temperature, warnings), a NEO-6M GPS gives real speed, and later the data moves onto a CAN bus.
Project 2 in this repo: a Linux kernel driver for the NEO-6M GPS.
